# Mídia do site

As imagens fornecidas para o site estão organizadas nesta pasta:

- `logotipo-adson.png` — logotipo transparente da navegação.
- `foto-principal.jpeg` — retrato principal do cabeçalho.
- `destaque-treinamento.jpeg` — imagem da seção de treinamentos.
- `adson-palestrando.jpeg` — foto de palestra na galeria.
- `panoramica.jpg` — panorama usado como fundo escurecido do cabeçalho.
- `footer.jpeg` — arte de marca no rodapé.
- `adson-retrato-chave.jpeg` e `adson-apontando-chave.jpeg` — retratos em fundo verde guardados para possíveis usos futuros.

As imagens públicas de prévia do Instagram também permanecem nesta pasta.
