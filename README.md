# Adson Treinamentos

Site institucional estático de Adson Silveira Santos, com apresentação profissional, treinamentos, e-book e contato via WhatsApp.

## Publicar no Cloudflare Pages

1. Importe este repositório no Cloudflare Pages.
2. Selecione a branch `main`.
3. Configure o diretório raiz como `/`.
4. Como não há etapa de build, deixe o comando de build vazio.
5. Publique. O ponto de entrada do site é `index.html`.

As imagens usadas pelo site estão em `assets/`.
